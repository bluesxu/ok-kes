# 出击模式按集火选目标，按卡牌描述出牌

精细化战斗实跑下来看着很乱：每张攻击牌都先拖到另外 1~2 个敌人身上悬停看击杀预览，141 次悬停只有 8 次打得死，牌在几个敌人之间晃来晃去，每张还多花约 1 秒。精英战里几个敌人血量相近时，「头目」按见过的最多血量认，会在几个敌人之间来回换。出牌只看类型标签和「出牌优先级」，不知道哪张牌抽牌、回费、丢牌，也不知道伤害多少。

改成下面的做法，分三步交付，每步跑一局看日志再做下一步。

## ① 选目标

- 普通战斗和精英战：集火「有攻击意图（认不出按攻击算）的敌人里血量 + 护盾最少的」，打到它死再换；都没有攻击意图时打血量 + 护盾最少的。别的敌人一张牌就能打死时先补刀，再回来。
- Boss 战：始终打 Boss（行动倒计时显示 ∞ 的那个）；小怪一张牌能打死时顺手清掉。不再用「见过的最多血量」认头目。
- 我方血量为 0 时照旧：先打有攻击意图、行动倒计时小的。

## ② 收集卡牌描述（只记录，不改出牌）

- 回合开始时，对手里本局还没读过的牌，按数字键选中后长按 CAPS 打开卡牌资讯，读完按 ESC 关掉。卡牌奖励页、闪光选择页上显示的描述顺手记下。
- 描述只在本局缓存，按「牌名 + 后缀 + 费用」区分；本局闪光、复制过的牌下次见到时重读，费用对不上也重读，换局清空。不做跨局资料库：一张牌有 5 种独特闪光，还有神闪和普通闪光，同名牌效果差别很大。
- 读不到（CAPS 没反应、弹窗没出来、读乱了）时本局记为「未知」，按原来的规则出，下场战斗再试，同一局最多试 2 次。读的过程中手牌数变了或冒出别的弹窗，就放弃这次读取，按 ESC 回到出牌画面。
- 描述写进战斗日志，攒到真实文本后再写「抽牌 / 生成 / 回费 / 丢牌 / 强化 / 群攻 / 伤害」的关键词规则。

## ③ 按描述出牌

每打一张牌都重新看手牌和 AP，不做整回合规划（回费牌、Ego、抽牌、丢牌、局外命运加入的牌让战局一直在变）：
1. 崩溃牌；有危险时先出防御牌。
2. 「出牌优先级」里的牌（手动覆盖）。
3. 0 费牌、回的 AP 不少于自身费用的牌；以及打完后剩余 AP ≥ 1 的抽牌、生成牌。手牌 10/10 或牌库、弃牌堆都空时，抽牌牌放到最后。
4. 强化牌。
5. 攻击牌：能用最便宜的一张打死当前目标就打它，否则按「伤害 ÷ 费用」从高到低。
6. 丢牌牌：描述里写了丢牌收益（抽牌、加伤害、回 AP）的按第 3 步处理；否则只有手里有打不出的牌可丢时才打。
7. 其余牌。Ego 沿用原逻辑。

判断「可能打死」：用描述里的实际伤害值作起点，局内每次出牌后按目标实际掉的血量和护盾、以及击杀预览读到的数字校准这场战斗的估计；估计伤害不低于敌人血量 + 护盾的 70% 才悬停确认，击杀预览的数字是最终依据。装备、增益让伤害在局内一直变，所以不跨局记伤害。

## Considered Options

- **跨局记每张牌的伤害**：有局外成长和局内装备，数值不可比，放弃。
- **按角色手写出牌组合配置（如「A>B」）**：工具的目的是减少人工操作，放弃。只保留「出牌优先级」「防御卡牌列表」作为手动覆盖。
- **整回合穷举出牌组合**：回费、抽牌、生成牌让结果无法预知，放弃，改为每步重新挑。

## Consequences

- 「精细化战斗」开关同时管描述收集和悬停确认；关闭时不读描述、不悬停，按类型标签出牌、集火打目标。
- 每局第一场战斗要为新见到的牌多花时间读描述（一局通常十几张牌）。
- CAPS 长按依赖后台按键，要实测确认；读描述的坐标和弹窗识别在游戏改版时要跟着改。
