# 出击模式的攻击牌一律拖到目标身上打出

自动出击模式原来用「数字键 + 回车」出牌，打的是游戏默认目标，没法选目标。现在改成：攻击牌一律拖到选定的敌人身上打出，非攻击牌仍然用按键 + 回车。这样做有三个原因：
- 输掉的轮次里约 8 成输在第一层 Boss 战，要优先打 Boss、先打死马上要行动的攻击意图小怪，都必须能选目标。
- 拖动途中悬停，能看到击杀预览（预扣血、骷髅图标）。
- 群攻牌只能靠击杀预览认出来，牌面上看不出来。

## Considered Options

- **全部保持按键 + 回车**：最快，但选不了目标，也拿不到击杀预览。
- **只对"需要选目标"的牌拖动**：群攻牌在牌面上认不出来，没法可靠地决定哪张牌需要拖，所以放弃。

## Consequences

- 每张攻击牌多花约 0.5 秒拖动时间；精细化战斗打开时，每张再加最多 3 次、每次约 0.3 秒的悬停预览。
- 加速模式里「按数字键后等卡牌上滑、回车后等手牌数减少」的出牌加速，只剩非攻击牌用得上；拖动出牌的等待要另外处理。
- 拖动依赖敌人在屏幕上的位置识别，以后游戏界面改版时这部分最先要跟着改。
