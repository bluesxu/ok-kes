# 卡厄思模式 / 出击模式：代码里每一个超过 0.5 秒的等待

ok-kes v1.4.3 源码静态扫描。按各模式 `PAGE_HANDLERS` 的顺序列出每个页面处理函数里的等待；
被多个页面共用的步骤（选卡、翻牌库、点击前悬停等）放在最后的「公共步骤」里，不在各页面里重复。

- **等待**：`sleep`、`click_box` 不写 `after_sleep` 时框架默认的 1 秒、`wait_*` 的超时、`swipe` 的时长。同一行点击后紧跟的 `sleep` 是连续累加的，例如「click_box 默认 1 秒 + sleep(1)」实际是 2 秒。
- **位置**：尾部 = 等完就结束这一轮；中间 = 等完还要继续操作或读画面（多步操作）。
- **装补丁后**：加速补丁对尾部等待用文字闸门判断页面是否已响应，响应了就提前继续，最长仍是原时长；但只有这一轮总共只点了一下时才生效。中间等待为了保证多步操作的时序，照原时长等满。
共 **160** 处。
